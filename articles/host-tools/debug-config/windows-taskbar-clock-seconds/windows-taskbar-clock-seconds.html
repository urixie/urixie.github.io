Windows 10 / 11 任务栏时钟显示秒：开启、验证与恢复

结合 Windows 10 22H2 与 Windows 11 25H2 的实际配置记录，整理任务栏秒数开关、图形设置、远程会话刷新、验证与恢复方法。

1. 适用环境与修改原理

Windows 10 的任务栏时钟通常只显示小时和分钟。如果希望直接看到秒数，可以修改当前用户的 Explorer 配置，再刷新任务栏。本文记录 Windows 10 Education 22H2（构建 19045.6456，PowerShell 7.6.5）与 Windows 11 25H2（构建 26200.8037）的实际配置，更新日期为 2026 年 10 月 22 日。Windows 11 远程配置过程及用户界面确认见第 8 节。

本次修改的位置是 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced，值名称为 ShowSecondsInSystemClock，类型为 REG_DWORD。将它设为 1 表示开启秒数，设为 0 表示关闭。该设置作用于对应用户，并不是整台电脑所有账号的统一开关。

版本范围：Windows 10 22H2 与 Windows 11 25H2 均在本次操作中写入了同名开关。Windows 11 用户也可优先使用第 8 节的系统设置入口；其他版本的界面位置及行为应以实际系统为准。

2. 使用 PowerShell 开启秒数

在需要显示秒数的那个 Windows 账号下打开 PowerShell。修改当前用户配置通常不需要管理员权限；不要为了执行命令切换到另一个管理员账号，否则修改的可能是另一个用户的配置。

2.1 先查看并记录原值

$clockPath = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced'
$clockName = 'ShowSecondsInSystemClock'

# 先确认 Explorer 配置项存在
Test-Path -LiteralPath $clockPath

# 记录原值；如果提示找不到该属性，记录为“原先不存在”
Get-ItemPropertyValue -LiteralPath $clockPath -Name $clockName

如果路径存在、但没有该属性，可以继续创建它。如果连整个 Advanced 路径都不存在，应先核对执行账号和运行环境，不要立即在陌生账号下新建整套 Explorer 配置。

2.2 创建或覆盖秒数开关

$clockPath = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced'
$clockName = 'ShowSecondsInSystemClock'

New-ItemProperty -LiteralPath $clockPath -Name $clockName `
    -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null

Get-ItemPropertyValue -LiteralPath $clockPath -Name $clockName

最后一行应输出 1。New-ItemProperty 可以创建注册表值，-Force 允许覆盖已有值；这避免了“该值尚不存在，直接修改失败”的情况。相关命令语义可参考 Microsoft Learn：使用注册表项。

3. 刷新任务栏，让设置生效

设置写入后，任务栏可能仍沿用原来的显示状态。本次通过重启当前登录会话中的 Windows 资源管理器应用配置，没有为此重启整台电脑。

手动操作更容易观察：按 Ctrl + Shift + Esc 打开任务管理器，在“进程”中找到“Windows 资源管理器”，选中后点击“重新启动”。桌面和任务栏会短暂消失后恢复。

刷新前：先等待资源管理器中的文件复制、移动等操作结束。重启资源管理器可能关闭文件夹窗口；它刷新的是桌面和任务栏的外壳进程。

需要用命令完成时，可在当前桌面会话的 PowerShell 中执行以下脚本。它只筛选与当前 PowerShell 相同会话的 explorer.exe，并在未自动恢复时启动资源管理器：

$desktopSession = (Get-Process -Id $PID).SessionId
Get-Process -Name explorer -ErrorAction SilentlyContinue |
    Where-Object SessionId -eq $desktopSession |
    Stop-Process -Force -ErrorAction Stop

Start-Sleep -Seconds 2
if (-not (Get-Process -Name explorer -ErrorAction SilentlyContinue |
          Where-Object SessionId -eq $desktopSession)) {
    Start-Process -FilePath "$env:WINDIR\explorer.exe" -WindowStyle Hidden
}

该脚本适用于在目标桌面会话中直接运行的情况，不要原样用于 SSH、服务、计划任务或其他用户的会话。尤其不能假定 SSH 的会话就是桌面会话；远程刷新时的实际处理见第 8 节。若任务栏未恢复，可在任务管理器中选择“文件 → 运行新任务”，输入 explorer.exe。

4. 分两步验证结果

先验证配置是否保存，再观察右下角时钟。注册表值为 1 只说明配置写入完成，并不能代替界面验收。

$clockPath = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced'
$desktopSession = (Get-Process -Id $PID).SessionId

[pscustomobject]@{
    ShowSecondsInSystemClock = (
        Get-ItemPropertyValue -LiteralPath $clockPath -Name ShowSecondsInSystemClock
    )
    ExplorerRunning = [bool](
        Get-Process -Name explorer -ErrorAction SilentlyContinue |
            Where-Object SessionId -eq $desktopSession
    )
} | ConvertTo-Json -Compress

此前 Windows 10 操作读回的结果如下，说明秒数开关已保存，且当前会话的资源管理器已恢复运行：

{"ShowSecondsInSystemClock":1,"ExplorerRunning":true}

最后检查右下角是否出现类似 14:35:08 的时间，并观察末尾秒数是否持续变化。Windows 10 操作记录保留了上述程序读回结果，没有采集时钟界面截图；该次实际显示效果仍以电脑上的观察为准。第 8 节的 Windows 11 操作则另有用户对界面的确认。

5. 不使用命令：通过注册表编辑器设置

  1. 在需要修改的用户桌面按 Win + R，输入 regedit 并打开注册表编辑器。
  2. 在地址栏输入下方路径，回车进入。
  3. 在右侧找到 ShowSecondsInSystemClock；不存在时，新建“DWORD（32 位）值”并使用该名称。即使系统是 64 位，这里的值类型仍选 DWORD（32 位）。
  4. 先记下原值，再把数值数据改为 1，点击确定。
  5. 按上一节方法重新启动 Windows 资源管理器，再观察任务栏时钟。
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced

这里操作的是与 PowerShell 方法相同的配置，无需将两种方法各执行一遍。如果通过输入另一个账号的凭据打开编辑器，也要核对其 HKEY_CURRENT_USER 是否仍对应目标用户。

6. 常见问题：命令成功了，为什么自己的时钟没变？

6.1 HKCU 跟随执行账号

HKCU 是 HKEY_CURRENT_USER 的简称，指运行命令的用户，而不是天然指向屏幕前正在使用电脑的人。自动化工具、沙盒、服务或切换账号运行的终端可能使用不同身份。

此前 Windows 10 初次检查就在自动化沙盒中遇到 Advanced 路径不存在；确认执行身份与桌面用户不同后，改为在实际登录用户上下文写入配置，随后成功读回 1。复用方法时，可以先执行以下只读命令，核对是否为预期的桌面账号：

[System.Security.Principal.WindowsIdentity]::GetCurrent().Name

6.2 数值正确，但任务栏仍未更新

  • 确认刷新的是目标桌面会话的资源管理器。
  • 确认数值名称拼写正确、类型是 REG_DWORD、数值为 1。
  • 如果安装了第三方任务栏或外壳工具，应检查该工具自己的时钟选项。
  • 刷新后仍不生效时，保存工作后注销并重新登录，或重启电脑，再观察效果。

7. 关闭秒数，或恢复原来的配置

如果只是想关闭秒数，将值设为 0，然后重新启动 Windows 资源管理器：

$clockPath = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced'
New-ItemProperty -LiteralPath $clockPath -Name ShowSecondsInSystemClock `
    -PropertyType DWord -Value 0 -Force | Out-Null

如果修改前该值不存在，希望恢复到“没有显式设置此项”的状态，可以删除这个值，再刷新资源管理器。只删除指定值，不删除整个 Advanced 项：

$clockPath = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced'
Remove-ItemProperty -LiteralPath $clockPath -Name ShowSecondsInSystemClock `
    -ErrorAction Stop

若修改前已经有值，应恢复为事先记录的原值。上述两种恢复方式按实际情况选择一种即可。

8. Windows 11 25H2：设置入口与远程实测

8.1 在目标桌面使用系统设置

微软当前的 Windows 11 帮助文档提供了图形界面入口：打开“设置 → 时间和语言 → 日期和时间”，找到系统托盘中的时间和日期选项，并勾选“在系统托盘时钟中显示秒数（耗电更多）”。具体位置和中文名称可能随版本变化，可在设置中搜索“秒”。参见 Microsoft Support：自定义 Windows 任务栏中的 Windows 11 说明。

本次 Windows 11 实测采用下述 SSH 与注册表方式，没有操作上述图形设置开关，因此两种操作路径的证据分开记录。

8.2 通过 SSH 核对版本与用户

目标是 Windows 11 25H2，完整构建号为 26200.8037。已使用用户授权的 SSH 服务登录；SSH 执行身份与目标桌面的登录账号一致。为保护隐私，本文不公开实际连接地址、计算机名、账号、SID 或密码。

以下命令在目标主机的 cmd 命令环境中执行，用来核对系统版本、用户和桌面进程。SSH 客户端可以从本地 PowerShell 发起，但连接后的默认命令环境取决于目标主机配置。

ver
whoami
query session
tasklist /FI "IMAGENAME eq explorer.exe" /V /FO CSV
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v DisplayVersion
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v UBR

现场输出表明：SSH 命令位于 services / Session 0，用户桌面位于 Console / Session 1。虽然账号相同，两者仍然是不同会话。刷新任务栏时必须针对实际桌面会话，不能把 SSH 中直接启动的新进程视为桌面任务栏已经恢复。

8.3 开启当前用户的秒数开关

修改前，目标用户的 ShowSecondsInSystemClock 值不存在。确认执行账号正确后，使用 Windows 原生的 reg.exe 创建开关：

reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v ShowSecondsInSystemClock
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v ShowSecondsInSystemClock /t REG_DWORD /d 1 /f
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v ShowSecondsInSystemClock

最后一次读取返回：

ShowSecondsInSystemClock    REG_DWORD    0x1

这条命令与前文 PowerShell 的注册表操作作用相同。本次远程操作使用原生命令完成，不依赖目标电脑安装 PowerShell 7。

8.4 恢复桌面任务栏并确认秒数

本次结束目标用户桌面会话中的资源管理器后，进程没有自动恢复。因此不能只执行结束进程命令就宣布完成，也不建议把远程强行结束 Explorer 作为普通用户的首选操作。有人可以操作目标桌面时，优先通过任务管理器的“重新启动”完成刷新。

现场通过一个临时的任务计划程序任务，使用目标用户已有的交互式登录令牌（InteractiveToken），在原来的 Console / Session 1 中重新启动 explorer.exe。没有为任务保存密码。随后重新查询，确认资源管理器属于同一桌面用户、位于原来的桌面会话，且秒数开关依然为 1。恢复用的临时任务和配置文件均已清理。

最终界面确认：用户在目标 Windows 11 桌面检查后确认，右下角时钟已经可以显示秒数。本次 Windows 11 记录同时具备配置读回、桌面进程恢复与用户界面确认。

如需撤销本次 Windows 11 修改，可按第 7 节删除原先不存在的该值，再通过目标桌面刷新任务栏。只想关闭秒数时，也可将其设为 0；不要删除整个 Advanced 项。
