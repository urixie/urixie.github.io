Verilog 组合逻辑与时序逻辑

Verilog 电路设计中，最核心的分类就是组合逻辑和时序逻辑。组合逻辑只由当前输入决定输出；时序逻辑由时钟触发，输出和当前状态有关。把这两类逻辑分清楚，是写出稳定 FPGA 代码的基础。

1.组合逻辑

组合逻辑没有记忆能力，输出只取决于当前输入。常见组合逻辑包括选择器.译码器.比较器.加法器.优先级编码器等。 

always @(*) begin
    case (sel)
        2'd0: y = a;
        2'd1: y = b;
        2'd2: y = c;
        default: y = 8'd0;
    endcase
end

组合逻辑一定要给所有分支赋值，否则综合工具可能推断出锁存器。

2.避免意外锁存器

如果组合逻辑中某些条件下没有给输出赋值，硬件为了保持之前的值，就可能生成 latch。大多数 FPGA 同步设计中应避免意外 latch。 

// 错误示例：en 为 0 时 y 没有赋值，可能推断 latch
always @(*) begin
    if (en)
        y = a;
end

// 推荐写法：先给默认值
always @(*) begin
    y = 8'd0;
    if (en)
        y = a;
end

3.时序逻辑

时序逻辑由时钟边沿触发，常用于寄存器.计数器.状态机.流水线和数据同步。时序逻辑的核心是“时钟边沿更新”。 

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        data_q <= 8'd0;
    else
        data_q <= data_d;
end

4.同步复位与异步复位

异步复位不依赖时钟，复位信号有效时立即复位；同步复位只在时钟边沿判断复位条件。工程中两种都常见，关键是整个项目风格要统一。 

// 异步低有效复位
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end

// 同步高有效复位
always @(posedge clk) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

5.计数器

计数器是最常见的时序逻辑。LED 闪烁.采样节拍.超时判断.波特率分频都可能用到计数器。

reg [15:0] cnt;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        cnt <= 16'd0;
    else if (cnt == 16'd999)
        cnt <= 16'd0;
    else
        cnt <= cnt + 1'b1;
end

6.边沿检测

边沿检测通常通过打一拍实现。把当前信号和上一拍信号比较，就能得到上升沿或下降沿脉冲。

reg trig_d;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        trig_d <= 1'b0;
    else
        trig_d <= trig;
end

assign trig_rise = trig & ~trig_d;

7.流水线

流水线通过插入寄存器把长组合路径拆短，提高时钟频率。代价是增加延迟，也就是数据要多等几个时钟周期才输出。

always @(posedge clk) begin
    stage1 <= a + b;
    stage2 <= stage1 * c;
    stage3 <= stage2 + d;
end

8.组合与时序检查清单

  • 组合逻辑是否所有分支都有赋值。
  • 时序逻辑是否使用非阻塞赋值。
  • 复位极性和复位方式是否统一。
  • 计数器最大值是否考虑位宽。
  • 边沿检测信号是否已经同步到当前时钟域。
  • 长组合路径是否需要加流水线。
