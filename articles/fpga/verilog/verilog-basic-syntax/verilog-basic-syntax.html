Verilog 基础语法与硬件描述思维

Verilog 不是普通软件语言，而是硬件描述语言。写 Verilog 的重点不是“程序一行一行执行”，而是描述电路结构.寄存器行为.组合逻辑和时序逻辑。本文从最基础的语法开始，建立面向 FPGA 的硬件描述思维。

初学 Verilog 最容易犯的错误，是把它当 C 语言写。C 语言描述的是 CPU 上顺序执行的指令，Verilog 描述的是并行存在的硬件电路。你写下的每个 always.assign.寄存器和连线，最终都要能对应到硬件结构。

1.Verilog工程的基本单位：module

module 是 Verilog 的基本设计单元，可以理解为一个硬件模块。模块有输入.输出和内部逻辑，综合后可能变成组合逻辑.触发器.RAM.DSP 或其它 FPGA 资源。 

module led_blink (
    input  wire clk,
    input  wire rst_n,
    output reg  led
);

endmodule

上面这个模块有一个时钟 clk.一个低有效复位 rst_n 和一个 LED 输出 led。端口方向决定信号从模块外进入还是从模块内输出。

2.wire 与 reg

wire 更像连线，常用于连续赋值和模块端口连接；reg 表示在过程块中被赋值的变量，综合后不一定都是寄存器，是否变成寄存器取决于 always 块写法。 

wire a_and_b;
reg  data_valid;

assign a_and_b = a & b;
  • assign 左侧通常是 wire。
  • always 块内赋值的信号通常声明为 reg。
  • reg 不等于一定综合成触发器。

3.assign连续赋值

assign 描述组合逻辑。只要右侧输入信号变化，左侧输出就会跟着变化，类似一根持续存在的硬件连线加组合门电路。 

assign y = (sel == 1'b1) ? a : b;
assign sum = data0 + data1;

4.always块

always 用于描述过程逻辑。根据敏感列表不同，可以描述组合逻辑，也可以描述时序逻辑。 

// 组合逻辑
always @(*) begin
    y = sel ? a : b;
end

// 时序逻辑
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end

always @(*) 常用于组合逻辑；always @(posedge clk) 常用于触发器和寄存器逻辑。

5.阻塞赋值与非阻塞赋值

阻塞赋值使用 =，语句按顺序立即更新；非阻塞赋值使用 <=，通常在时钟边沿统一更新。工程中建议遵循：组合逻辑用阻塞赋值，时序逻辑用非阻塞赋值。 

// 组合逻辑推荐用 =
always @(*) begin
    y = a & b;
end

// 时序逻辑推荐用 <=
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end
初学阶段不要在同一个 always 块中混用复杂的阻塞和非阻塞赋值。尤其是时序逻辑中误用阻塞赋值，仿真行为和综合后硬件理解都容易出错。

6.参数化设计

parameter 可以让模块更容易复用。例如计数器位宽.FIFO 深度.数据总线宽度都适合参数化。 

module counter #(
    parameter WIDTH = 16
)(
    input  wire             clk,
    input  wire             rst_n,
    output reg [WIDTH-1:0]  cnt
);

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        cnt <= {WIDTH{1'b0}};
    else
        cnt <= cnt + 1'b1;
end

endmodule

7.基础编码检查清单

  • 模块端口方向是否清晰。
  • 组合逻辑是否覆盖所有分支，避免锁存器。
  • 时序逻辑是否统一使用非阻塞赋值。
  • 复位极性是否统一，例如 rst_n 表示低有效。
  • 位宽是否明确，避免无意识截断或扩展。
  • 参数化模块是否在边界值下验证过。
