Verilog 组合逻辑与时序逻辑

Verilog 电路设计中，最核心的分类就是组合逻辑和时序逻辑。组合逻辑只由当前输入决定输出；时序逻辑由时钟触发，输出和当前状态有关。把这两类逻辑分清楚，是写出稳定 FPGA 代码的基础。

1. 组合逻辑

组合逻辑没有记忆能力，输出只取决于当前输入。常见组合逻辑包括选择器、译码器、比较器、加法器、优先级编码器等。 

always @(*) begin
    case (sel)
        2'd0: y = a;
        2'd1: y = b;
        2'd2: y = c;
        default: y = 8'd0;
    endcase
end

组合逻辑一定要给所有分支赋值，否则综合工具可能推断出锁存器。

2. 避免意外锁存器

如果组合逻辑中某些条件下没有给输出赋值，硬件为了保持之前的值，就可能生成 latch。大多数 FPGA 同步设计中应避免意外 latch。 

// 错误示例：en 为 0 时 y 没有赋值，可能推断 latch
always @(*) begin
    if (en)
        y = a;
end

// 推荐写法：先给默认值
always @(*) begin
    y = 8'd0;
    if (en)
        y = a;
end

3. 时序逻辑

时序逻辑由时钟边沿触发，常用于寄存器、计数器、状态机、流水线和数据同步。时序逻辑的核心是“时钟边沿更新”。 

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        data_q <= 8'd0;
    else
        data_q <= data_d;
end

4. 同步复位与异步复位

异步复位不依赖时钟，复位信号有效时立即复位；同步复位只在时钟边沿判断复位条件。工程中两种都常见，关键是整个项目风格要统一。 

// 异步低有效复位
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end

// 同步高有效复位
always @(posedge clk) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

5. 计数器

计数器是最常见的时序逻辑。LED 闪烁、采样节拍、超时判断、波特率分频都可能用到计数器。

reg [15:0] cnt;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        cnt <= 16'd0;
    else if (cnt == 16'd999)
        cnt <= 16'd0;
    else
        cnt <= cnt + 1'b1;
end

6. 边沿检测

边沿检测通常通过打一拍实现。把当前信号和上一拍信号比较，就能得到上升沿或下降沿脉冲。

reg trig_d;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        trig_d <= 1'b0;
    else
        trig_d <= trig;
end

assign trig_rise = trig & ~trig_d;

7. 流水线

流水线通过插入寄存器把长组合路径拆短，提高时钟频率。代价是增加延迟，也就是数据要多等几个时钟周期才输出。

always @(posedge clk) begin
    stage1 <= a + b;
    stage2 <= stage1 * c;
    stage3 <= stage2 + d;
end

8. 时钟使能，而不是门控时钟

需要“每秒动作一次”“每 100 个周期采样一次”时，初学者常用计数器产生一个低频信号，再拿它当时钟驱动其他寄存器。这在 FPGA 中是要避免的：

  • 逻辑产生的“时钟”不走全局时钟网络，到达各个寄存器的时间差（偏斜）很大，时序无法保证。
  • 两个时钟之间形成了跨时钟域，需要额外的同步处理。
  • 用组合逻辑控制时钟（门控时钟，如 assign gclk = clk & en;）还会产生毛刺，导致寄存器误触发。

正确的做法是：所有寄存器使用同一个时钟，用使能信号控制它们什么时候更新。

// 推荐：1ms 节拍使能（50MHz 时钟）
localparam integer TICK_DIV = 50_000;
reg [15:0] tick_cnt;
wire       tick_1ms = (tick_cnt == TICK_DIV - 1);

always @(posedge clk) begin
    tick_cnt <= tick_1ms ? 16'd0 : tick_cnt + 1'b1;
    if (tick_1ms)                      // 每 1ms 更新一次，仍然是同一个 clk 驱动
        ms_counter <= ms_counter + 1'b1;
end

FPGA 的每个触发器都有专用的时钟使能（CE）端口，使能写法会直接映射到 CE，不额外消耗逻辑。确实需要不同频率的时钟（例如外设接口要求），应使用 PLL / MMCM 产生，并按跨时钟域规则处理数据交互。

9. FPGA 中的复位策略

上一节提到“同步复位和异步复位都可以，关键是统一”，在 FPGA 工程中还可以更进一步：

  • FPGA 上电配置完成后，所有寄存器已经处于确定的初始值（代码中的初值，或默认 0）。这和 ASIC 上电后状态随机不同。
  • 因此，数据通路寄存器（流水线数据、移位寄存器、乘法器输入输出）通常不需要复位。去掉这些复位后，综合工具可以把它们合并进 DSP、SRL（移位寄存器 LUT）或 BRAM，资源和时序都会改善。
  • 控制通路必须复位：状态机、计数器、valid / 握手信号、错误标志，要保证复位后处于确定状态。
  • 外部复位按钮或上电复位是异步信号，进入每个时钟域前都要经过“异步复位、同步释放”的复位同步器，见 跨时钟域处理。

复位对时序的影响和更多细节，见 时序收敛方法。

10. 让代码映射到正确的硬件资源

同一个功能，写法不同，综合出的硬件资源可能完全不同。几种常见结构的推荐写法：

功能映射目标写法要点
乘法、乘加DSP 硬核操作数位宽不超过 DSP 端口（7 系列为 25×18），输入输出各打一拍以利用 DSP 内部寄存器
长移位寄存器 / 延迟线SRL（LUT 实现的移位寄存器）不要复位，不要读取中间级，只读取末端或固定级
大数组BRAM同步读，不要整体复位，见 FIFO 与 RAM
小查找表LUT / 分布式 RAMcase 或常量数组
计数器、加法器LUT + 进位链正常写法即可，宽计数器注意时序

综合完成后，查看资源报告中的 DSP、BRAM、SRL 使用量，确认关键结构确实映射到了预期的资源上。如果一个本该用 BRAM 的数组消耗了几千个寄存器，说明写法不符合推断规则。

11. 工作场景：按键消抖与长按检测

把同步、计数器、边沿检测组合起来，实现一个可靠的按键处理模块：

module key_debounce #(
    parameter CLK_HZ  = 50_000_000,
    parameter DEB_MS  = 20,
    parameter LONG_MS = 1000
) (
    input  wire clk,
    input  wire rst_n,
    input  wire key_n,          // 按下为低，异步输入
    output reg  short_press,    // 短按：松开时输出一个周期脉冲
    output reg  long_press      // 长按：达到时长时输出一个周期脉冲
);
    localparam integer DEB_CNT  = CLK_HZ / 1000 * DEB_MS;
    localparam integer LONG_CNT = CLK_HZ / 1000 * LONG_MS;

    // 1. 两级同步，消除亚稳态
    (* ASYNC_REG = "TRUE" *) reg [1:0] key_sync;
    always @(posedge clk) key_sync <= {key_sync[0], ~key_n};
    wire key_raw = key_sync[1];                // 1 表示按下

    // 2. 消抖：电平连续稳定 DEB_MS 才更新
    reg [31:0] deb_cnt;
    reg        key_stable, key_stable_d;
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            deb_cnt <= 0; key_stable <= 1'b0;
        end else if (key_raw == key_stable) begin
            deb_cnt <= 0;
        end else if (deb_cnt == DEB_CNT - 1) begin
            deb_cnt <= 0; key_stable <= key_raw;
        end else begin
            deb_cnt <= deb_cnt + 1'b1;
        end
    end

    // 3. 边沿检测 + 按下时长计数
    reg [31:0] hold_cnt;
    reg        long_fired;
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            key_stable_d <= 1'b0; hold_cnt <= 0; long_fired <= 1'b0;
            short_press <= 1'b0; long_press <= 1'b0;
        end else begin
            key_stable_d <= key_stable;
            short_press  <= 1'b0;
            long_press   <= 1'b0;
            if (key_stable && !key_stable_d) begin          // 按下沿
                hold_cnt <= 0; long_fired <= 1'b0;
            end else if (key_stable) begin
                if (!long_fired && hold_cnt == LONG_CNT - 1) begin
                    long_press <= 1'b1; long_fired <= 1'b1;
                end else if (!long_fired) begin
                    hold_cnt <= hold_cnt + 1'b1;
                end
            end else if (!key_stable && key_stable_d) begin // 松开沿
                if (!long_fired) short_press <= 1'b1;
            end
        end
    end
endmodule

这个模块体现了几条原则：异步输入先同步；所有逻辑使用同一个时钟；输出是单周期的寄存器脉冲，没有毛刺；时间参数由 parameter 和时钟频率计算得出，换时钟时不需要改代码。

12. 组合与时序检查清单

  • 组合逻辑是否所有分支都有赋值。
  • 时序逻辑是否使用非阻塞赋值。
  • 复位极性和复位方式是否统一。
  • 计数器最大值是否考虑位宽。
  • 边沿检测信号是否已经同步到当前时钟域。
  • 长组合路径是否需要加流水线。
  • 是否用时钟使能代替逻辑分频时钟和门控时钟。
  • 数据通路是否去掉了不必要的复位，控制通路复位是否经过同步释放。
  • 乘法、移位寄存器、大数组是否按推断规则编写，综合后是否映射到 DSP、SRL、BRAM。
  • 异步输入（按键、外部信号）是否先经过两级同步再做消抖和边沿检测。
