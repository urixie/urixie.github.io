AVR 架构详解

AVR 是 Atmel（现 Microchip）于 1997 年推出的 8 位微控制器架构，以其创新的 Flash 程序存储器和高效的 RISC 指令集迅速成为嵌入式开发和创客教育的标杆。Arduino 所使用的 ATmega328P 正是 AVR 架构的典型代表。本文以 ATmega48/88/168/328 和 ATtiny 系列为参考，详细整理 AVR 内核架构。

AVR 是最早在微控制器中集成 Flash 存储器的架构之一（与 PIC 类似）。Arduino 的成功让 AVR 成为全球最流行的 8 位 MCU 架构。理解 AVR 的 Harvard 架构（程序和数据分离）和单周期指令设计，有助于理解其他 8 位 MCU 的设计思路。

1.AVR 架构概述

1.1 架构特点

AVR 采用 Harvard 架构（程序存储器和数据存储器分离）和单周期指令执行：

  • 单周期指令：大多数指令在 1 个时钟周期内完成（8051 需要 12 个机器周期），大幅提升执行效率。
  • Harvard 架构：程序总线和数据总线独立，指令读取和数据访问可以同时进行。
  • 内置 Flash：程序存储器直接集成在芯片内，支持数万次擦写。
  • 寄存器文件：32 个通用寄存器（0~31），可直接参与指令操作，无需累加器中转。
  • RISC 指令集：约 130 条指令（不同型号略有差异），大多数是单字（16 位）指令。

1.3 内核结构

AVR 内核主要由以下部件组成：

  • ALU：算术逻辑单元，直接对 32 个通用寄存器进行操作。
  • 程序计数器 PC：负责指令地址计算。
  • 堆栈指针 SP：16 位，指向当前堆栈位置（支持超过 256 字节的 SRAM）。
  • 状态寄存器 SREG：存放 ALU 运算结果标志（H.I.T.S.V.N.Z.C）。
  • Flash 控制器：通过 16/32 位指令预取缓冲读取程序。

2.寄存器模型

2.1 通用寄存器

AVR 有 32 个 8 位通用寄存器（R0~R31）。这些寄存器直接连接到 ALU，无需像 8051 那样经过累加器：

寄存器别名说明
R0~R31—通用寄存器，可用于任何指令操作数。
R26~R27X16 位间接寻址寄存器（X = R27:R26）。
R28~R29Y16 位间接寻址寄存器（Y = R29:R28）。
R30~R31Z16 位间接寻址寄存器（Z = R31:R30），还用于程序计数器相关寻址。

注意：R0 和 R1 有特殊用途。R1 固定为 0（用于 MUL 乘法指令结果）。R0 用于 SPM 指令（Flash 自编程）。

2.2 状态寄存器 SREG

SREG（状态寄存器）包含 ALU 运算结果标志：

位符号名称说明
7I全局中断使能置 1 使能所有中断。中断响应时自动清零，返回时恢复。
6T位复制存储BLD（位加载）和 BST（位存储）指令使用。
5H半进位标志BCD 运算时用于低 4 位向高 4 位进位。
4S符号标志S = N ⊕ V（负数和溢出的异或）。
3V溢出标志有符号数运算溢出时置 1。
2N负数标志结果最高位为 1 时置 1。
1Z零标志结果为 0 时置 1。
0C进位标志无符号运算进位或借位时置 1。

2.3 堆栈指针 SP

AVR 的堆栈指针是 16 位寄存器（SPH:SPH），可以指向最大 64KB 的 SRAM 空间：

  • 堆栈向下增长（Push 时 SP 递减）。
  • 中断和函数调用使用堆栈保存返回地址（2 字节）。
  • 局部变量也存放在堆栈中。

3.存储结构

3.1 存储空间映射

AVR 采用 Harvard 架构，有三个独立的存储空间：

  • 程序存储器（Flash）：存放程序代码和常量表。AVR 是 16 位/32 位指令，Flash 按字（word，16 位）编址。
  • 数据存储器（SRAM）：0x0000~0x005F 为 I/O 寄存器区，0x0060 开始是通用 SRAM 区。
  • EEPROM：独立的数据存储空间，可字节访问，典型寿命 10 万次擦写。

3.2 SRAM 布局（ATmega328P 为例）

地址区域说明

4.指令系统

4.1 指令格式

AVR 指令长度有 16 位（单字）和 32 位（双字）两种：

  • 单字指令：大多数指令（ADD.MOV.LDI.CPI 等）。
  • 双字指令：需要较大立即数的指令（LDS.STS.CALL.JMP 等）。

4.3 寻址方式

  • 立即数寻址：LDI Rd, K（K 为 0~255 立即数）。
  • 直接寻址：STS/LDS（SRAM 地址）。
  • 寄存器直接寻址：MOV Rd, Rr。
  • 寄存器间接寻址：LD Rd, X/Y/Z（X=R27:R26，Y=R29:R28，Z=R31:R30）。
  • 带后增量的寄存器间接寻址：LD Rd, X+/Y+/Z+。
  • 带预减量的寄存器间接寻址：LD Rd, -X/-Y/-Z。
  • 程序存储器寻址：LPM（读取 Flash 中的常量表）。

5.中断系统

5.1 中断机制

AVR 的中断是向量式，每个中断源有固定的向量地址：

  • 中断向量位于 Flash 程序存储器的起始区域。
  • 向量地址按中断优先级顺序排列（编号越小优先级越高）。
  • 向量处通常放置 JMP 指令跳转到实际中断处理程序。
  • 进入中断时，硬件自动清除 SREG 的 I 位（禁止嵌套），返回时自动恢复。

5.3 中断控制寄存器

  • EICRA：外部中断控制寄存器（INT0.INT1 触发方式：上升/下降/低电平）。
  • EIMSK：外部中断屏蔽寄存器（INT0.INT1 使能）。
  • PCICR：引脚变化中断控制寄存器。
  • PCMSK0~2：引脚变化中断屏蔽寄存器。

5.4 全局中断

SREG 的 I 位是全局中断使能位：

  • sei（SET I）：置位 I，全局使能中断。
  • cli（CLR I）：清零 I，全局禁止中断。
  • 进入中断时 I 位自动清零，返回时自动恢复（如果使用了 RETI 指令）。

6.定时器系统

6.1 ATmega328P 定时器

ATmega328P 有 3 个定时器：

  • Timer/Counter0：8 位，通用 PWM 和定时。
  • Timer/Counter1：16 位，高精度定时和 PWM。
  • Timer/Counter2：8 位，支持异步操作（可用作 RTC）。

6.2 定时器模式

  • 普通模式：计数器从 0 向上计数到 TOP（0xFF 或 OCR0A），然后溢出回到 0。
  • CTC 模式（Clear Timer on Compare）：计数器计到 OCRn 时清零，可产生精确频率。
  • 快速 PWM 模式：计数器从 0 向上到 TOP，然后直接回到 0（单斜坡）。
  • 相位修正 PWM：计数器从 0 向上到 TOP，再向下到 0（双斜坡），适合电机控制。

6.3 定时器寄存器

  • TCNTn：定时器计数器寄存器（当前计数值）。
  • OCRnA/B：输出比较寄存器（匹配时触发动作）。
  • ICRn：输入捕获寄存器（Timer1 专用）。
  • TCCRnA/B/C：定时器控制寄存器（模式.分频.输入捕获设置）。
  • TIMSKn：定时器中断屏蔽寄存器。
  • TIFRn：定时器中断标志寄存器。

7.串口通信

7.1 USART 寄存器

  • UDRn：USART 数据寄存器（发送/接收缓冲）。
  • UCSRnA/B/C：USART 控制和状态寄存器（工作模式.中断使能等）。
  • UBRRnH/L：USART 波特率寄存器（16 位，分高低字节）。

7.2 波特率计算

波特率 = fosc / (16 × (UBRR + 1))

例如：16MHz 晶振，9600 波特 → UBRR = 16000000 / (16 × 9600) - 1 = 103.167 ≈ 103

8.工程实践要点

  • 熔丝位：AVR 有丰富的熔丝位（CKSEL.SUT.CKDIV8 等），决定时钟源.启动延时.BOD 电平等。上电复位后首次编程需正确配置熔丝位。
  • 看门狗：使能看门狗后，必须定期执行 WDR（喂狗）指令，否则芯片会复位。
  • Arduino Bootloader：ATmega328P 出厂自带 Arduino Bootloader（1KB），支持串口上传程序。如果不需要 Bootloader，可以禁用以节省 1KB Flash 空间。
  • 熔丝位不可逆：某些熔丝位（如 SPIEN）需要高电压并行编程才能修改，一旦锁定可能无法再通过 ISP 编程。
  • 省电模式：AVR 支持 Idle.ADC Noise Reduction.Power-save.Power-down.Standby.Extended Standby 等多种省电模式，通过 SMCR 寄存器选择。
