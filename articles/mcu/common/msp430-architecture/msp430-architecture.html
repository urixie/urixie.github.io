MSP430 · TI · 16-BIT · MIXED-SIGNAL

MSP430 架构详解

MSP430 是德州仪器（TI）于 1996 年推出的 16 位混合信号微控制器系列，以其极低的功耗和丰富的模拟外设集成而著称。MSP430 采用独特的Von Neumann 架构（统一程序和数据空间）和基于寄存器的设计，是超低功耗应用的经典选择。本文以 MSP430x2xx 系列（如 MSP430G2553.MSP430F5529）为参考，详细整理 MSP430 内核架构。

MSP430 的设计哲学是"超低功耗"。它的 CPU 可以在 1μs 内从低功耗模式唤醒，活动模式电流仅约 100μA/MHz，待机电流可低至 1μA 以下。这使 MSP430 成为电池供电传感器.智能仪表.医疗设备的首选。

1.MSP430 架构概述

1.1 核心特点

  • 16 位 RISC 架构：简洁的指令集，大多数指令单周期执行。
  • Von Neumann 架构：程序和数据共用 16 位地址总线和数据总线（统一存储空间）。
  • 基于寄存器：16 个 16 位通用寄存器（R0~R15），减少内存访问。
  • 16 位数据总线：内部寄存器.运算单元.地址总线均为 16 位。
  • 20 位地址总线：可寻址 1MB 地址空间（分段式：16 个 64KB 段）。
  • 内置 Flash：支持在系统编程（Flash 编程无需高电压）。
  • 低功耗设计：多种低功耗模式（LPM0~LPM4），CPU 可在 1μs 内唤醒。

1.2 CPU 结构

MSP430 CPU 主要组成：

  • 16 个通用寄存器（R0~R15）：R0=PC（程序计数器），R1=SP（堆栈指针），R2=SR（状态寄存器），R3=CG（常量发生器），R4~R15=通用寄存器。
  • 算术逻辑单元 ALU：支持 16 位有符号/无符号运算。
  • 程序计数器 PC：20 位，指向下一条指令地址。
  • 状态寄存器 SR：包含运算标志和控制位。
  • 常量发生器 CG：R3 读取时返回 0.1.2.4.8 等常量，无需立即数指令。

2.寄存器模型

2.1 通用寄存器

MSP430 有 16 个 16 位通用寄存器（R0~R15），但前 4 个有特殊用途：

寄存器名称功能说明
R0PC（Program Counter）程序计数器，指向下一条指令地址。20 位，可寻址 1MB 空间。指令长度决定 PC 增量（2 或 4 字节）。
R1SP（Stack Pointer）堆栈指针，指向当前栈顶。堆栈向下增长，16 位，指向 SRAM 区域。
R2SR（Status Register）状态寄存器，包含标志位和控制位。20 位，但低 16 位可用。
R3CG（Constant Generator）常量发生器。读取 R3 返回预定义的常量值（0.1.2.4.8 或 .FETCH/.INMASK），写入被忽略。
R4~R15—通用寄存器，可用于任何指令操作数。

2.2 状态寄存器 SR

位名称说明
0Z零标志，运算结果为 0 时置 1。
1C进位标志，无符号运算进位或借位时置 1。
2N负数标志，结果最高位为 1 时置 1。
3GIE全局中断使能，置 1 使能所有可屏蔽中断。
4CPUOFFCPU 关闭位，置 1 进入低功耗模式。
5OSCOFF振荡器关闭位，置 1 关闭外部晶振。
6SCG0系统时钟发生器关闭位 0。
7SCG1系统时钟发生器关闭位 1。
8~15V溢出标志，有符号运算溢出时置 1。

CPUOFF.OSCOFF.SCG0.SCG1 四位组合决定进入哪种低功耗模式：

  • LPM0：CPUOFF=1，其余为 0。
  • LPM1：CPUOFF=1，SCG0=1。
  • LPM2：CPUOFF=1，SCG1=1。
  • LPM3：CPUOFF=1，SCG0=1，SCG1=1。
  • LPM4：CPUOFF=1，OSCOFF=1，SCG0=1，SCG1=1。

3.存储结构

3.1 地址空间

MSP430 采用 Von Neumann 架构（统一存储），地址空间最大 1MB（20 位地址）：

地址范围大小区域说明
0x0000~0x00FF256B特殊功能寄存器外设寄存器映射。
0x0100~0x01FF256B8 位外设看门狗.Timer_A.B.比较器.等 8 位外设。
0x0200~0x09FF2KB16 位外设ADC.USCI.UCS 等 16 位外设。
0x0A00~0xFFFF~60KBRAM/Flash取决于芯片型号。低地址为 RAM，高地址为 Flash。
段 1~F64KB/段代码/数据段分段式寻址，段选择通过程序计数器高位或段寄存器。

3.2 Flash 布局

Flash 分为多个段：

  • 信息段 A/B：通常 256 字节（128W），存放芯片型号.ID.校准数据等。可以用作普通 Flash 存储。
  • 主程序段：存放用户程序代码。
  • BSL 段（Bootstrap Loader）：出厂预置的引导加载程序，用于串口或 USB 更新固件。

4.指令系统

4.1 指令格式

MSP430 指令长度有双字节（1 word）和单字节（emulated 指令）两种：

  • 格式 1（双操作数）：Opcode(4) | S(1) | D(1) | Ad(1) | As(1) | Rd(4) | Rr(4) | ——
  • 格式 2（单操作数）：Opcode(4) | Ad(1) | As(1) | Rd(4) | ——
  • 格式 3（跳转指令）：Offset(10) | 0 | J | Opcode(3) | ——

4.3 寻址方式

MSP430 支持 4 种源操作数寻址方式和 3 种目的操作数寻址方式：

As 值寻址方式示例说明
00寄存器模式MOV R5,R6操作数在寄存器中。
01变址模式MOV 2(R5),R6基址 R5 + 偏移量。
10间接寄存器模式MOV @R5,R6操作数地址在 R5 中。
11间接自增模式MOV @R5+,R6先取 R5 地址，再 R5+=2。

目的操作数只能是寄存器模式或立即数模式（R3 常用作 0 值）。

4.4 模拟指令（Emulated Instructions）

由于 R3=常量发生器，很多指令实际上不存在硬件（由汇编器转换）：

  • CLR x → MOV #0,x
  • SETC → BIS #1,SR
  • CLRC → BIC #1,SR
  • DINT → BIC #8,SR（GIE 位清零）
  • EINT → BIS #8,SR（GIE 位置 1）

5.中断系统

5.1 中断向量表

MSP430 中断向量位于 Flash 最高地址区域（每个向量 2 字节）：

5.2 中断响应过程

  1. 外设中断请求到达。
  2. 如果 GIE=1 且该外设中断已使能，CPU 响应中断。
  3. 当前 PC 入栈（堆栈 -= 2）。
  4. SR 入栈（保存进入中断前的状态寄存器）。
  5. GIE 自动清除（禁止嵌套）。
  6. PC 跳转到对应中断向量地址。
  7. 执行中断处理程序，最后执行 RETI。
  8. RETI 从堆栈恢复 SR 和 PC，继续执行被中断代码。

5.3 中断嵌套

MSP430 默认不支持中断嵌套（因为进入中断时 GIE 自动清除）。如果要支持嵌套，需要在中断处理程序中重新使能 GIE： 

#pragma vector=PORT1_VECTOR
__interrupt void Port1_ISR(void) {
    _EINT();        // 在嵌套前重新使能全局中断
    // 处理中断
}

6.低功耗特性

6.1 低功耗模式

MSP430 的核心优势是极低的功耗。通过设置 SR 中的 CPUOFF.OSCOFF.SCG0.SCG1 位进入不同低功耗模式：

模式CPUACLKMCLKSMCLK典型电流
Active运行运行运行运行~300μA/MHz
LPM0关闭运行关闭运行~70μA
LPM1关闭运行关闭关闭~20μA
LPM2关闭运行关闭关闭~8μA
LPM3关闭运行关闭关闭~1μA
LPM4关闭关闭关闭关闭<0.1μA

6.2 唤醒源

不同低功耗模式支持不同的唤醒源：

  • LPM0~LPM3：可由外设中断唤醒（Timer.SPI.UART.ADC 等）。
  • LPM4：只有外部复位.RTC 报警（某些型号）和 NMI 可唤醒。

6.3 时钟系统

MSP430 有三个内部时钟：

  • ACLK（Auxiliary Clock）：辅助时钟，通常来自低频晶振（32.768kHz），用于低速外设。
  • MCLK（Master Clock）：主时钟，CPU 和高速外设使用。
  • SMCLK（Sub-Main Clock）：子主时钟，高速外设使用。

时钟源可以选择内部 DCO（数控振荡器，~1MHz）或外部晶振（32768Hz 或高速晶振）。

7.工程实践要点

  • 看门狗：复位后看门狗默认使能（1s 溢出），程序必须先停止或周期喂狗，否则芯片不断复位。
  • Flash 写入：写入 Flash 前必须先解锁（写入特定序列到 FCTL3.FCTL1），写入期间 CPU 暂停。
  • 堆栈：堆栈在 SRAM 区，向下增长。调用函数和中断都会压栈，局部变量过多可能导致栈溢出。
  • 中断向量定位：中断向量地址由芯片决定，参考数据手册。不同 MSP430 型号向量表可能不同。
  • FRAM 型号：MSP430 FRAM 系列（如 MSP430FR2433）使用 FRAM 而非 Flash，功耗更低，擦写次数更多（10^15 次）。
