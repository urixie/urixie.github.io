PIC32 · MIPS · M4K · MICROCHIP · 32-BIT

PIC32 MIPS 架构详解

PIC32 是 Microchip 推出的 32 位微控制器系列，基于 MIPS Technologies 的 M4K 处理器内核。MIPS（Microprocessor without Interlocked Pipeline Stages）是一种经典的 RISC 架构，以其高效的流水线设计和简洁的指令集在嵌入式领域广泛应用。本文以 PIC32MX 和 PIC32MZ 系列为参考，详细整理 MIPS M4K 内核架构。

PIC32 的 MIPS 内核与标准 MIPS32 有一些差异：Microchip 对原始 MIPS 设计做了定制（如去除了互锁流水线的要求，简化了内存管理）。学习 PIC32 时，理解 MIPS 的寄存器约定和调用规范是调用 C 库和 RTOS 移植的基础。

1.MIPS 架构概述

1.1 MIPS 特点

  • RISC 设计原则：固定 32 位指令长度（所有指令都是 32 位），简单的指令格式，Load-Store 架构（运算指令只对寄存器操作）。
  • 5 级流水线：Fetch.Decode.Execute.Memory.Writeback，每周期一条指令流出。
  • 互锁流水线：标准 MIPS 要求指令按序执行，数据/结构冒险由硬件互锁检测解决（Microchip 的 M4K 可能简化了这部分）。
  • 32 个通用寄存器：$0~$31，每个 32 位。
  • 无条件延迟槽：分支跳转指令后有一条延迟槽（delay slot），通常放一条不依赖分支结果的指令。
  • 协处理器接口：支持协处理器 CP0（系统控制）、CP1（浮点）、CP2/3（用户自定义）。

2.寄存器模型

2.1 通用寄存器

MIPS 有 32 个 32 位通用寄存器 $0~$31：

寄存器别名用途
$0$zero硬编码为 0，写入被忽略，读取恒为 0。
$1$at汇编临时寄存器（assembler temporary），汇编器使用。
$2~$3$v0.$v1函数返回值（32 位以下用一个，64 位以下用两个）。
$4~$7$a0~$a3函数参数（前四个参数）。
$8~$15$t0~$t7临时寄存器，调用者保存（caller-saved）。
$16~$23$s0~$s7保存寄存器，被调用者保存（callee-saved）。
$24~$25$t8.$t9临时寄存器，调用者保存。
$26~$27$k0.$k1内核临时寄存器，供操作系统/异常处理使用。
$28$gp全局指针（Global Pointer），指向全局数据段起始地址。
$29$sp堆栈指针（Stack Pointer），必须 8 字节对齐。
$30$fp帧指针（Frame Pointer），指向当前函数栈帧。
$31$ra返回地址（Return Address），JAL/JALR 自动保存返回地址。

2.2 特殊寄存器

  • PC（Program Counter）：32 位程序计数器，指向当前指令地址。
  • HI/LO：乘除法结果寄存器。HI 存高 32 位，LO 存低 32 位。
  • CP0（协处理器 0）：系统控制和缓存管理寄存器组。

2.3 CP0 寄存器（系统控制）

CP0 是 MIPS 的系统控制协处理器，包含缓存管理.异常处理.内存管理等功能：

寄存器名称功能
$0IndexTLB 索引。
$1RandomTLB 随机替换寄存器。
$2EntryLo0TLB 偶数页物理地址。
$3EntryLo1TLB 奇数页物理地址。
$4Context上下文指针。
$5PageMask页面大小掩码。
$6WiredTLB 有线寄存器数量。
$8BadVAddr最近错误虚地址。
$9Count计数寄存器（Timer）。
$10EntryHiTLB 虚地址高半部分。
$11Compare定时器比较寄存器（与 Count 配合产生中断）。
$12Status状态寄存器（全局中断使能.IE.运行模式等）。
$13Cause最近异常原因编码。
$14EPC异常程序计数器（Exception PC）。
$15PRId处理器标识。

3.指令系统

3.1 指令格式

MIPS 所有指令都是 32 位，分为三种格式：

  • I 类型（立即数）：[opcode(6)][rs(5)][rt(5)][imm(16)] — 用于加载存储.条件分支.立即数运算。
  • J 类型（跳转）：[opcode(6)][target(26)] — 用于绝对跳转 J/JAL。
  • R 类型（寄存器）：[opcode(6)][rs(5)][rt(5)][rd(5)][shamt(5)][funct(6)] — 用于寄存器-寄存器运算。

3.3 延迟槽

MIPS 分支和跳转指令后面有一个延迟槽（delay slot），紧接分支/跳转的下一条指令会被执行： 

    beq $t0, $t1, label
    nop                 ; 延迟槽，通常填 NOP
label:
    ...

延迟槽的目的简化流水线设计。编译器通常在这里放一条与分支结果无关的指令（如 NOP）。

4.存储管理

4.1 地址空间

PIC32 的虚拟地址空间（32 位）：

  • kseg0：0x8000_0000~0x9FFF_FFFF（512MB），直接映射到物理内存，无缓存。
  • kseg1：0xA000_0000~0xBFFF_FFFF（512MB），直接映射到物理内存，无缓存（用于外设寄存器）。
  • kseg2：0xC000_0000~0xDFFF_FFFF（512MB），虚拟地址，需要 TLB 转换。
  • useg：0x0000_0000~0x7FFF_FFFF（2GB），用户态地址，需要 TLB 转换，有缓存。

4.2 Flash 和 RAM 映射

  • Flash：从物理地址 0x1FC0_0000 开始（kseg0/kseg1 映射到 0x9FC0_0000）。
  • SRAM：从物理地址 0x0000_0000 开始（kseg0 映射到 0x8000_0000）。
  • 外设：通常映射到 kseg1 区域（0xBF00_0000~0xBF80_0000）。

4.3 TLB（Translation Lookaside Buffer）

PIC32MZ 等高端型号有完整 TLB，支持内存分页：

  • PIC32MX 系列没有 TLB，使用固定映射。
  • PIC32MZ 有 32~64 项 TLB，支持可配置的页面大小。

5.中断机制

5.1 中断类型

MIPS 中断分为软件中断和硬件中断：

  • 软件中断：SIP（SW Interrupt Pending），可由程序触发（设置 Cause.SIP 位）。
  • 硬件中断：IRQ0~IRQ5，共 6 个外部中断源（通过 MIPS CPU 的 INT 引脚输入）。

5.2 中断控制

CP0 Status 寄存器中的 IE 位控制全局中断使能：

  • IE（bit[0]）：全局中断使能位。
  • EXL（bit[1]）：异常级别，置 1 禁止所有中断进入。
  • ERL（bit[2]）：错误级别，更高级别的屏蔽。
  • IM7~IM0（Status bits[15:8]）：各中断源的独立使能位。

5.3 向量表

MIPS 中断向量位于固定地址：

  • 0x8000_0000（Reset）：复位向量。
  • 0x8000_0180（General Exception）：通用异常。
  • 0x8000_0200（Interrupt）：中断向量。

Microchip 的 PIC32 库通常将向量表重定向到 RAM 或 Flash，以便运行时修改。

6.PIC32 特有外设

6.1 重要外设

  • PORTA~PORTZ：最多 16 个 GPIO 端口。
  • Timer1~5：16/32 位定时器。
  • UART1~6：串口，支持 DMA。
  • SPI1~4：SPI 主/从接口。
  • I2C1~5：I2C 主/从接口。
  • OC1~5：输出比较/PWM 模块。
  • IC1~5：输入捕获模块。
  • ADC：10/12 位模数转换器。
  • CAN1~2：CAN 总线接口（部分型号）。
  • USB OTG：USB 控制器（部分型号）。
  • Eth：10/100/1000 Ethernet MAC（部分型号）。
  • CRC：硬件 CRC 计算单元。
  • RNG：随机数发生器。

6.2 DMA 控制器

PIC32MZ 内置增强型 DMA 控制器：

  • 多个独立 DMA 通道（8~16 个）。
  • 支持内存到外设.外设到内存.内存到内存的传输。
  • 与 CPU 并行工作，不占用 CPU 带宽。

7.开发工具链

7.1 MPLAB X IDE + XC32

Microchip 官方开发环境：

  • MPLAB X IDE：基于 NetBeans 的免费 IDE。
  • XC32 编译器：基于 GCC，专门针对 MIPS（-mips32r2 选项）。
  • MPLAB Harmony：驱动和中间件库（可选）。

7.2 调试

  • ICD4/PICKit4：硬件调试器。
  • JTAG/SWD：调试接口。

8.工程实践要点

  • 延迟槽：汇编代码中分支跳转后必须有一条指令（通常放 NOP）。C 编译器会自动处理。
  • 堆栈对齐：MIPS ABI 要求堆栈 8 字节对齐。函数调用前后 $sp 必须 8 字节对齐。
  • 寄存器保存：$t0~$t9 是调用者保存（caller-saved），$s0~$s7 是被调用者保存（callee-saved）。函数调用时注意哪些寄存器需要保存。
  • 乘除法：MULT 等乘法指令结果在 HI:LO 寄存器对中，需要 MFHI.MFLO 取出。
  • PIC32 的 ERET：从异常返回使用 ERET 指令，它会恢复 Status 和 EPC 并重新使能中断。
  • 内存布局：PIC32 的程序 Flash 和数据 RAM 地址是分开的，链接脚本需要正确配置段（.text/.data/.bss）。
  • MIPS16e：部分 PIC32 支持 MIPS16e 压缩指令模式，可以减少代码体积约 40%。编译器选项 -mips16。
