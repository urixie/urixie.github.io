iVentoy PXE安装Windows与网卡驱动处理

iVentoy 可以让一台电脑作为 PXE 启动服务器，另一台电脑通过网卡从网络启动并加载 ISO 镜像安装系统。它适合没有 U 盘、批量装机、临时给另一台电脑安装 Windows 的场景。本文重点整理 Windows 原版 ISO 通过 PXE 安装时的网卡驱动问题。

重点结论：原版 Windows ISO 不一定包含目标电脑的有线网卡驱动。PXE 安装过程中，前期能从网卡启动，不代表进入 Windows PE / Windows 安装程序后仍然能识别这块网卡。解决思路通常有两种：使用兼容性好的 USB 转网口，或者把目标网卡驱动注入到 boot.wim / install.wim 中。

一、iVentoy PXE安装的基本链路

PXE 安装需要两端：服务端运行 iVentoy，客户端从网卡启动。客户端通过 DHCP/TFTP/HTTP 等方式获取启动文件，再加载 ISO 安装系统。

二、原版Windows镜像与iVentoy项目地址

PXE 装机时建议优先使用微软官方原版 ISO，再按目标电脑补充网卡、存储控制器、芯片组等驱动。这样比使用未知来源的二次打包镜像更容易定位问题。

  • 微软官方 Windows 11 下载页面：可下载 Windows 11 ISO、安装助手和媒体创建工具。
  • 微软官方 Windows 10 下载页面：可通过媒体创建工具生成 ISO 或安装 U 盘。
  • iVentoy 官方下载页面：官方页面给出的 Free Edition 下载入口指向 GitHub Releases。
  • iVentoy GitHub 开源部分地址：ventoy/PXE。
  • iVentoy GitHub Releases 下载页。
注意：iVentoy 官方 GitHub Release 说明中明确写到，Ventoy 和 iVentoy 是两个不同软件；Ventoy 是 100% 开源，iVentoy 是“部分开源、部分闭源”，ventoy/PXE 仓库只包含 iVentoy 的开源部分。

三、服务端准备

  1. 在服务端电脑下载并解压 iVentoy。
  2. 把 Windows 10 / Windows 11 ISO 放入 iVentoy 指定的 ISO 目录。
  3. 服务端电脑和客户端电脑接入同一局域网，或者两台电脑通过网线直连。
  4. 启动 iVentoy 服务，确认监听网卡选择正确。
  5. 确认防火墙没有拦截 iVentoy 相关服务。

如果两台电脑网线直连，建议服务端使用固定 IP，并确认 iVentoy DHCP 服务工作正常。网络里如果已有路由器 DHCP，要避免多个 DHCP 服务冲突。

四、客户端设置PXE启动

  1. 进入客户端 BIOS / UEFI。
  2. 开启 Network Boot / PXE Boot。
  3. 根据实际情况选择 UEFI PXE 或 Legacy PXE。
  4. 把网卡启动临时设为第一启动项，或用启动快捷键选择网卡。
  5. 进入 iVentoy 菜单后选择 Windows ISO。

新机器通常优先选择 UEFI PXE；老机器可能需要 Legacy PXE。安装模式应尽量和目标磁盘分区方式匹配：UEFI 对应 GPT，Legacy 对应 MBR。

五、为什么PXE能启动，Windows安装却没网

PXE 启动早期使用的是网卡固件、UEFI PXE 驱动或 BIOS PXE 能力；进入 Windows 安装环境后，控制权转到 Windows PE / Windows 安装程序。这时候能否继续访问网络，取决于 Windows PE 中是否带有目标网卡驱动。

阶段谁在驱动网卡常见问题
PXE启动前期BIOS/UEFI 网卡固件能拿到启动文件
进入WinPE/安装程序Windows PE 内置驱动原版 ISO 可能没有目标网卡驱动
Windows第一次进桌面已安装系统驱动可能仍然没网，需要离线安装驱动

六、方案一：使用USB转网口

如果目标电脑内置网卡太新，原版 Windows ISO 没有驱动，最省事的办法通常是插一个兼容性好的 USB 转网口。很多 USB 有线网卡芯片在 WinPE 或 Windows 中更容易被识别。

  • 优点：不需要改 ISO，操作快，适合临时装机。
  • 缺点：需要额外硬件；不是所有 USB 网卡都一定免驱。
  • 适用场景：临时给一台电脑安装系统、目标机内置网卡不识别、赶时间。

你之前遇到“使用 USB 转网口就可以”的现象，本质就是 Windows 安装环境识别了 USB 网卡驱动，但没有识别目标电脑内置网卡驱动。

七、方案二：向原版ISO注入网卡驱动

如果希望不用 USB 转网口，或者需要批量安装同型号电脑，可以把目标网卡驱动注入到 Windows 安装镜像中。通常至少要关注两个文件：

  • boot.wim：Windows PE / 安装环境。PXE 安装过程中能否识别网卡，主要看这里。
  • install.wim 或 install.esd：最终安装到硬盘上的 Windows 系统镜像。第一次进系统后是否有网，主要看这里。

只给 install.wim 注入驱动，可能解决进系统后的驱动问题，但不一定解决安装环境中没网的问题；PXE 场景更应该优先处理 boot.wim。

八、DISM注入驱动示例

在 Windows 主机上可以使用 DISM 挂载 WIM 并添加驱动。示例仅展示思路，实际路径按自己的 ISO 解压目录和驱动目录调整。

mkdir C:\mount\boot
mkdir C:\mount\install

Dism /Mount-Wim /WimFile:D:\iso\sources\boot.wim /Index:2 /MountDir:C:\mount\boot
Dism /Image:C:\mount\boot /Add-Driver /Driver:D:\drivers\lan /Recurse
Dism /Unmount-Wim /MountDir:C:\mount\boot /Commit

Dism /Get-WimInfo /WimFile:D:\iso\sources\install.wim
Dism /Mount-Wim /WimFile:D:\iso\sources\install.wim /Index:1 /MountDir:C:\mount\install
Dism /Image:C:\mount\install /Add-Driver /Driver:D:\drivers\lan /Recurse
Dism /Unmount-Wim /MountDir:C:\mount\install /Commit

如果 ISO 中是 install.esd，可以先转换为 install.wim，再注入驱动。驱动目录中应包含 .inf 文件，单独的 .exe 安装包通常不能直接注入，需要先解压出驱动文件。

九、PXE安装完成后避免再次进入PXE

Windows 安装过程中会多次重启。第一次把系统文件释放到硬盘后，重启时如果仍然优先从 PXE 启动，就会再次进入 iVentoy 菜单，看起来像“安装循环”。

  • 首次重启后，进入 BIOS 把系统盘设为第一启动项。
  • 或者在启动菜单中手动选择 Windows Boot Manager。
  • 如果只是临时 PXE 启动，不要把 PXE 永久设为第一启动项。

十、常见问题排查

现象优先排查方向

能进菜单但加载ISO失败ISO路径、文件名、服务端网络、防火墙、镜像完整性

十一、工程检查清单

  • 服务端和客户端是否在同一网络，或直连网络是否配置正确。
  • iVentoy 监听的是否是连接客户端的那块网卡。
  • 网络中是否存在多个 DHCP 服务冲突。
  • Windows ISO 是否来自微软官方下载页面。
  • iVentoy 是否来自官方下载页或 GitHub Releases。
  • 目标电脑内置网卡驱动是否已经准备。
  • PXE 场景是否优先给 boot.wim 注入网卡驱动。
  • 安装完成第一次重启后，是否改回系统盘启动。
